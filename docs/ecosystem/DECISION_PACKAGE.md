# Decisions only the owner can take (one package)

Prepared 2026-10-17, status column added 2026-10-18. **A recommendation in this table is a proposal, never an approval.** An item is approved
only when its Status says APPROVED with a date and scope. In particular, a recommended financial-treatment option (marked **F**) does NOT
enable any new posting, mapping or journal: nothing in the ecosystem posts a Fleet fact other than the workshop invoice until the owner
approves that specific item. Operational-policy items are marked **P**. Work on open items may prepare code behind the recommended option
only where it changes no posted accounting data and can be switched off; it is never switched on without the owner's word.

Approved so far: **item 3** (invitation link for users added from a product), **item 4** (central seat limits) and **item 10** (first Admin Tenant without e-mail), each only for the scope written in its Status cell (owner messages 2026-10-18). Those approvals do not extend to any other row.
